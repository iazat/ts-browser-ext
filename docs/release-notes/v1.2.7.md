Tailscale 1.104.2 underneath. Nothing changes in either extension; the release is the backend.

No re-registration is needed — the native messaging host name has not changed since v1.2.1. Upgrading still means replacing the backend binary, since it is copied into your browser's configuration directory at install time:

```
go run github.com/iazat/ts-browser-ext@latest --install=C<your-extension-id>   # Chrome
go run github.com/iazat/ts-browser-ext@latest --install=F                      # Firefox
```

Building the backend now needs Go 1.27.3 or newer, which is what Tailscale 1.104.2 requires. A `go` command with its default toolchain setting fetches that for you; one pinned with `GOTOOLCHAIN=local` reports the version instead of building.

## The tailnet name comes from Status alone

Tailscale 1.104 took the netmap off the IPN bus: `Notify.NetMap` is gone, and a watcher that asks for `NotifyInitialNetMap` or `NotifyRateLimit` is turned away. This backend only read the netmap for the tailnet name shown in the popup, and every status it sends already asks LocalAPI `Status` for the same name, so the netmap is no longer requested and the watcher subscribes to state and prefs only.

If that `Status` call fails, the popup shows no tailnet name until the next status goes out. It used to fall back to the last netmap.
